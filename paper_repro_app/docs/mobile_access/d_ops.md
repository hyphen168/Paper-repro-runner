# 手机控制 · 运维与状态设计规范（d_ops）

定位：让"论文复现助手"具备电脑常在线、可恢复、状态可见的远程使用底座。本规范与局域网/公网接入方案（网络角色）、访问口令方案（安全角色）配套；与既有约束 G-1"关窗即断"、G-7"重跑补密码"衔接，不改其语义，只补可执行习惯与自愈手段。

## 决策

D1 拓扑：手机控制 = 常驻运行的电脑端 app（唯一状态源）+ 一条接入链路。链路分两档，均零新框架、无新增第三方依赖：
- 局域网档：app 显式"远程开关"后 bind 0.0.0.0:8505 并放行防火墙，手机同网直连；
- 公网档：复用用户 AutoDL 云机（公网可达、已有 SSH 凭据与 ssh_utils/RemoteRunner 多机候选逻辑）跑 ssh -R 反向隧道，把 8505 映射到云机公网端口，电脑无公网 IP 亦可达。Tailscale/frp/ngrok/花生壳需新客户端/账号且国内可达性不稳，仅列备选不默认引入。
D2 默认安全：默认仍 bind 127.0.0.1（保持 P0-3 免防火墙弹窗），远程模式须显式开启，绝不改默认；两档都在应用层加一次性访问口令（Streamlit 无内置登录，不引入登录框架；口令沿用"仅存进程内存、不落盘不写明文"策略），公网档另有 SSH 隧道加密兜底。
D3 常驻三支柱：接电电源策略（合盖不休眠）、开机自启、双击幂等（start_app.py 已有端口占用检测→免二开）。控制台窗口=任务执行线程与隧道守护进程的共同宿主，G-1"关窗即断"保留，并把"勿关窗口"从禁令升级为可执行的养机习惯与崩溃自愈文案。
D4 在线判断以状态文件为准：app 进程内置守护线程每 30s 刷新 ~/.paper_repro_app/heartbeat.json（记录进程号、启动时间、最近刷新），页面每次刷新额外打点。手机端显示"运行时长/最后刷新"；心跳停滞超阈值即提示"疑似离线"，先查电脑再重连，而非盲目等待连接超时。进程级心跳可区分三种状态：进程存活且空闲、页面正被刷新、电脑睡眠或已崩溃。
D5 轮询节流：桌面 2s 监控轮询不变；手机访问自动降频至 5s，省流量省电，并避免手机后台标签页持续推送。

## 可执行变更

E1 远程启动与多开适配（start_app.py/bat）：
- 新增 --remote 参数：等价改传 --server.address 0.0.0.0；首次以管理员执行一次性放行 netsh advfirewall firewall add rule name="PaperRepro 8505" dir=in action=allow protocol=TCP localport=8505；随后打印三行访问地址：本机 http://127.0.0.1:8505、局域网 http://<get_local_ips() 首址>:8505、公网（隧道挂载后）http://<AutoDL 域名>:<映射端口>。
- 多开保护分支适配远程场景：命中"8505 已在运行"时不自动弹浏览器（避免无人值守时桌面骚扰），改为打印上述地址清单并退出，手机可直接抄录。
- 新增 start_app_remote.bat = start_app.bat --remote，兼作开机自启与隧道宿主脚本的目标。
E2 常驻指引（并入 GUIDE G-1 与 FRIEND_GUIDE）：
- 电源计划文案：控制面板→电源选项→更改计划设置→更改高级电源设置→睡眠设为"接通电源：从不"；笔记本另设"关闭盖子时→接通电源→不采取任何操作"。口诀：接电源、可合盖、不关机。
- 开机自启：Win+R 输入 shell:startup 回车打开启动文件夹，将 start_app_remote.bat 快捷方式放入；说明多开检测保证重复点击不二开。
E3 断线场景矩阵（新增 scripts/tunnel_keepalive.py，复用 ssh_utils 候选主机探测逻辑）：
- 电脑睡眠→唤醒：隧道脚本以 ssh -R 0.0.0.0:<远端端口>:127.0.0.1:8505 -N -o ServerAliveInterval=15 -o ServerAliveCountMax=3 -o ExitOnForwardFailure=yes 挂载，异常退出后 sleep 5 循环自动重连；app 无需重启，手机刷新即恢复。若睡眠过久云端会话被清，任务页会出现既有"后台线程已不在运行"警示，按 G-7 补密码点「重新执行流水线」即可恢复。
- 隧道断（云机重启/换机）：同上循环自愈；多台候选自动挑可达者，与提交任务时主机探测同源。
- app 崩溃：控制台已打印退出码与中文排查（G-1）；动作为关闭窗口→重新双击 start_app_remote.bat（自检/重建环境）→隧道脚本探测到远端端口恢复即自动续挂。
- 手机断线：任务由电脑端线程驱动，与手机连接无关——重开页面即连，任务不中断，仅实时日志暂停滚动。
E4 状态可见性（app.py 头部胶囊，复用 pr-pill 样式）：
- 展示"应用运行时长 Xh Ym · 最后刷新 HH:MM:SS"；心跳超 90s 未更新转告警色并提示"疑似离线：检查电脑是否睡眠或窗口被关，重新双击 start_app.bat 恢复"。数据仅为进程元信息，无敏感内容。
- 手机监控页轮询支持查询参数或会话开关把 run_every 从 2.0 调至 5.0，桌面默认不变。
E5 协调文案（统一替换/补强"勿关控制台"表述）：
- 主句："控制台窗口是任务与手机连接的宿主：合盖可以，关机、关窗不行。手机显示离线时，先看电脑是否睡眠、窗口是否被关；重新双击启动脚本即可自愈。"
