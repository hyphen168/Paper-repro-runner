# 侧栏与功能入口重构规范 v1.0（主导裁决版）

三份报告（a_audit / b_ia / c_onboard）已通读。事实校准先行：侧栏实际代码顺序为 遇到问题？先看这里(809) → AI 助手(822) → [条件]手机直达与受信设备(873) → 云端配置(905) → 当地定位与天气(918) → 背景天气预览(945)，全代码仅一处 st.sidebar；以代码为准（父会话此前描述顺序有误，不影响结论）。根因共同确认：新功能入口全部「折叠 + 条件渲染 + 折叠态不自述」，手机/受信/AI 配置在桌面默认模式不可发现，用户原话「看不到」由此而来。本规范为实施唯一依据，冲突处以本文为准。

## 一、总纲

1. 折叠也自述：每个折叠容器在折叠态必须有状态徽章或自描述标题，绝不只露空标题。
2. 模式永不隐身：远程/手机相关入口常驻渲染；桌面模式展示「如何开启」指引而非功能列表，杜绝误导也不隐身。
3. 引导一次即安静：首次配置/首帧引导采用会话内一次性提示，不弹层、不常驻、不打扰。
4. 零回归护栏：口令门安全语义、表单空白默认、密码框 type、凭据 DPAPI/内存、无 emoji、零新框架、104 测试全绿、AppTest 0 异常，均为硬约束。
5. 单实现防漂移：失败诊断、档案、受信管理每域只保留一份渲染器，监控与历史共用。

## 二、侧栏最终结构

固定五组，自上而下：

- A 云服务器与任务：配置目录与「当前任务」行（原云端配置 caption 精简为「云端只执行、产物留本机」）+ 仓库档案管理（自历史记录 tab 平移）。
- B 智能助手：状态徽章行（折叠可见）+ expander。
- C 手机与远程：状态徽章行 + expander，无环境变量门（常驻）。
- D 环境与氛围：城市定位 + 天气预览（原两段合并）。
- E 帮助与手册：FAQ 压缩为前 3 条 + 4 条远程/隧道/防火墙/自启条目 + 详细手册链接（原顶部 expander 下移）。

各组默认展开策略（首帧一次，之后交还用户会话状态）：A 引导态 True（会话首帧且历史无 success 任务）否则 False；B 未配置 True / 已配置 False；C 桌面模式 True（矮指引）远程模式 False（重管理体）；D/E False。常态即「五条自述标题 + 至多一组展开」。

## 四、引导与发现终版

机制：_one_shot(key) 帮助函数（session_state 布尔，不落盘、无凭据、同会话至多一次）；升级提示版本号经 config_store（合并写不覆盖云端字段）。

触发点三条（主区、无 emoji）：
1. 手机（桌面模式会话首帧，主区顶部）：「手机控制默认关闭：当前为桌面本机模式。需要手机查看时用 start_app_remote.bat 启动，侧栏会出现直达地址与受信设备管理。」
2. AI（首次任务失败且未配置，失败卡顶部一次）：「失败任务可一键 AI 分析根因（发送前自动脱敏）。在侧栏智能助手填服务商、模型与 API Key 并测试保存解锁。」
3. 档案（首次出现「填入上次成功配置」按钮时一次）：「同一仓库第二次提交自动记住成功命令与数据集；历史页档案管理区可查看删除。」

轮播改功能条后保留滚动机制；B 徽章常驻属状态而非提示，不占一次性配额。成功页仅补条件 caption，不加成功态 AI 复盘（避免制造新噪音）。

## 五、实施顺序与验收

实施顺序：P0-1 → P0-2/3/4（侧栏五组一次成型）→ P0-5 → P0-6（空态+轮播+一次性）→ P0-7 → P1 文案批。

验收：
1. pytest 104 全绿、AppTest 0 异常（含新增断言：桌面模式五组标题存在、B 组未配置自动展开、C 组桌面模式渲染指引而非设备列表、失败卡存在「去配置 AI」按钮）。
2. 对照 diff：所有被重排控件均带显式 key（sb_ / rp_ / tk_ 前缀续用）。
3. 桌面模式人工巡检：五组标题 + 徽章首屏可见、无 emoji、无假按钮、AI 未配置自动展开、折叠再展开状态保留。
4. 远程模式回归：lan 与 tunnel 各起一次，口令门直通、受信签发/吊销、直达地址分流文案正确。
5. 打包泄漏扫描零命中；副本 AppTest 0 异常。

不做清单：不做侧栏悬浮/折叠动画；不做搜索框索引；不改轮播 CSS 动画时长；不在 C 组放口令修改框；不把 model_override 持久化；不新增弹层组件库；不动 .streamlit 主题色。
