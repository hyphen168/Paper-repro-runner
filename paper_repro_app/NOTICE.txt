Paper Repro Runner · NOTICE
============================

依赖许可（经 pip 安装到用户虚拟环境，不构成二进制再分发）：
- streamlit: Apache-2.0
- pandas / numpy: BSD-3-Clause
- requests: Apache-2.0
- beautifulsoup4 / PyYAML / pydantic: MIT
- paramiko: LGPL-2.1（仅动态链接方式使用）
- pytest（开发用，分发版不安装）: MIT

外部服务（用途与隐私影响，详见使用说明「网络与隐私」一节）：
- ip-api.com：公网 IP 粗粒度城市定位（免费档非商用）
- Open-Meteo：天气与地理编码（NOAA/官方公开模型，建议保留署名）
- GitHub / Gitee / arXiv：论文与代码仓库检索
- 清华 / 阿里 / 腾讯等 pip 镜像：依赖下载测速择优
- download.pytorch.org：CUDA 版 PyTorch 安装
- ghfast.top / 清华 Miniconda：GitHub 与安装包加速

凭据安全承诺：
- 云服务器密码只存在于进程内存，重启即失效；不落盘、不入日志、不入安装包
- 粘贴私钥仅保存在本机 ~/.ssh/ 目录（0600）
- 日志统一脱敏（PEM/密码关键字替换）

数据与算法：
- 昼夜/太阳位置算法基于 NOAA 简化模型；天气数据来自 Open-Meteo
- 论文数值对比基准与出处见 paper_claims.json 与任务报告口径注记
- 公开数据集请核对各自原始许可后使用

本工具仅供研究与学习用途，不构成对任何论文结论的替代验证。
