# 论文复现流水线版升级记录

## 1. 项目目标

将原先的轻量本地控制端升级为更接近真实工程项目的论文复现流水线，重点包括：

- 论文链接 -> 仓库识别
- 本地任务与日志持久化
- 云端执行步骤拆解
- 复现流程按阶段管理
- 更明确的工程化交付结构

## 2. 升级重点

### 2.1 任务状态模型

本地 SQLite 任务表新增了 `current_step` 字段，用于记录任务当前处于哪个阶段，例如：

- prepare
- clone
- env
- install
- verify
- collect

这样可以让任务从“单次命令执行”升级为“阶段化流程控制”。

### 2.2 单脚本远程执行

之前的实现问题是：每条命令都在独立 SSH 会话中执行，导致 venv / conda 激活状态无法保留。 这会造成依赖安装和测试命令实际没有在同一运行环境中执行。

本次升级后，远程执行采用：

- 一个 bash 脚本
- 一次 SSH 会话
- 统一执行顺序：准备目录 -> 拉代码 -> 创建环境 -> 安装依赖 -> 验证 -> 收集日志

### 2.3 工程化 UI

本地界面从“单任务提交”升级为“工程流水线展示”，新增：

- 流水线步骤展示
- 任务状态显示
- 当前步骤显示
- 日志与结果回收

### 2.4 可执行入口修正

修正了包入口问题，确保 `python -m paper_repro_app` 或 `paper_repro_app` 的方式能够进入正确的程序入口。
