核心能力

⚙️

本地控制 + 云端执行

本地保留任务和日志，云端负责代码拉取、依赖安装和复现验证，保障控制权和数据安全。

🧠

智能环境诊断

自动识别 Python、CUDA、依赖文件和运行方式，推荐最适合的 conda / venv / docker 路径。

📊

分析与报告输出

从论文、仓库和日志中提炼创新点、风险、结论，并生成 Markdown / JSON 报告。

复现工作流

01

输入论文

填入论文链接或代码仓库候选，完成初始任务录入。

02

识别仓库

系统尝试从页面文本里解析可能的 GitHub / GitLab / Hugging Face 项目。

03

诊断环境

自动检查 Python、依赖和 GPU 要求，减少重复调试。

04

执行复现

拉取代码、安装依赖、执行脚本，并持续同步日志状态。

05

输出结论

整理结果、提炼创新要点，并生成适合展示和汇报的结案文档。

系统架构

控制端

用 Streamlit 构建本地交互界面，提供论文输入、任务管理、日志一览和交互式控制。

Streamlit SQLite 任务队列

执行端

通过 SSH / 用户自有云服务器完成重计算，确保本地机不承担大规模执行成本。

SSH Paramiko 云端脚本
