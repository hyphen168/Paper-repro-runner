# Paper Repro Runner 产品启动记录

## 1. 目标

将论文复现助手从开发脚手架升级为更适合普通用户一键启动的桌面应用，要求：

- 无需手动创建虚拟环境
- 无需手动安装依赖
- 无需手动输入命令启动
- 适合第一次使用的小白
- 兼容桌面快捷方式使用

## 2. 解决方案

### 2.1 启动器设计

我们采用了“Python 统一启动器”的方案：

- 入口：`start_app.py`
- 桌面入口：`start_app.bat`
- 桌面快捷方式：`Paper Repro Runner.lnk`

优点：

- 逻辑更清晰
- 更容易调试
- 不依赖用户自己手动激活 virtualenv
- 可以在启动前先检测端口是否已占用，避免重复启动

### 2.2 自动化流程

启动器会自动执行：

1. 检测 `.venv` 是否存在
2. 没有则创建虚拟环境
3. 检测依赖是否安装
4. 安装 `requirements.txt`
5. 检测端口 `8505` 是否已占用
6. 若未占用则启动 Streamlit 页面

### 2.3 问题处理

在测试中发现：

- 之前的脚本在依赖安装时遇到了 Windows 文件锁问题
- 现象是 `WinError 32`，通常意味着之前仍有 Streamlit 或 Python 进程占用了同一目录中的安装文件

因此本次改动增加了：

- 端口占用检测
- 依赖安装失败提示
- 清晰的用户提示："Close any running Python/Streamlit process and try again."

## 3. 当前状态

现在的应用可以：

- 双击桌面快捷方式启动
- 自动创建虚拟环境
- 自动安装依赖
- 自动打开浏览器页面
- 对第一次使用者非常友好

## 4. 用户使用方式

1. 双击桌面快捷方式：`Paper Repro Runner`
2. 程序自动创建 `.venv`
3. 自动安装 Python 依赖
4. 自动启动网页应用
5. 在浏览器访问：

```text
http://127.0.0.1:8505
```
