# 论文复现助手 · 排障手册（GUIDE）

> 按"哪一步失败"查表。错误消息中的锚点（如 G-3.3）指向下表行。本手册与 UI 建议动作一一对应，是唯一步骤源。

## G-0 总原则

1. 先看任务详情页顶部**结论行**与**建议操作**（错误码 E_* 开头）。
2. 按建议执行后仍失败 → 复制"诊断摘要"发给朋友/AI 助手（按钮在失败卡片上）。
3. 数据全部在本机：任务在 `用户目录/.paper_repro_app` 与数据目录；应用文件夹可随时删除重装，不影响记录。

## G-1 本地启动失败

| 症状 | 原因 | 动作 |
|---|---|---|
| 双击 start_app.bat 无反应/提示无 Python | 未装 Python 或版本过低 | 安装 Python 3.11+（安装时勾选 Add to PATH），重试 |
| 首次启动装依赖很久后失败 | 镜像源同步延迟 | 重试会自动换镜像；仍失败手动执行：`.venv\Scripts\python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 浏览器打开是"无法访问此网站" | 服务还没就绪 | 等日志出现"已启动"后刷新页面 |
| 关掉黑色控制台窗口后任务消失 | 设计约束：后台任务随窗口存活 | 运行期间不要关闭控制台；长时间任务请保持窗口 |

## G-2 连接云端失败（提交前"测试 SSH 连接"或任务连接阶段）

| 症状 | 原因 | 动作 |
|---|---|---|
| 无法连接（拒连/超时/不可达） | 实例关机、地址是旧的、网络不通 | 打开云控制台确认开机；**整行复制**最新登录指令（形如 `ssh -p 38662 root@connect.xxx.seetacloud.com`）粘贴到"服务器地址"框（支持多行多台自动选用可达者） |
| SSH 认证失败 | 密码错 / 密钥与公钥不配对 / 端口旧 | 核对密码（AutoDL 在控制台实例页设置/重置）；或点「注入公钥到服务器」 |
| 未找到可用认证源 | 没填密码也没填私钥 | 填密码；或私钥路径/粘贴 -----BEGIN 开头的 PEM 全文 |
| 新实例提示无 python/conda | 干净实例 | 系统会自动安装 Miniconda（清华镜像，需几分钟），请勿中断 |

## G-3 环境与依赖失败

| 锚点 | 症状 | 原因 | 动作 |
|---|---|---|---|
| G-3.1 | 云端自动装 Python 失败 | 网络或镜像问题 | 按错误提示手动安装 Miniconda 后重试（错误里有命令） |
| G-3.2 | conda 版本与仓库要求不符 | 环境固定 python 3.10 | 联系维护者确认；一般 3.10 兼容绝大多数仓库 |
| G-3.3 | `Torch not compiled with CUDA enabled` | PyTorch 是 CPU 版/缺失 | **重新执行任务**即可：系统自动卸载旧版并从官方 CUDA 源（cu121→cu128）重装（每源限时 700s，约 3-8 分钟） |
| G-3.4 | `ModuleNotFoundError: xxx` | 依赖安装曾被跳过 | 重新执行任务（新版会在依赖失败时中断并列出缺包）；个别可选包（tensorflow/onnx 等）缺失不影响训练 |
| G-3.5 | 依赖安装非常慢 | 大包下载 | 耐心等待（pip 已自动多源切换）；超时后重试 |

## G-4 克隆与运行入口失败

| 锚点 | 症状 | 原因 | 动作 |
|---|---|---|---|
| G-4.1 | 仓库拉取超时/失败 | GitHub 国内不可达/私有仓库 | 系统已自动用加速源重试；私有仓库需在"代码仓库候选"填可访问地址 |
| G-4.2 | 未识别训练入口 | 仓库脚本命名特殊（trainer.py 等）或在子目录 | 切「实际运行」模式，粘贴仓库 README 的训练命令；失败诊断卡可一键把命令带回提交页修改 |
| G-4.3 | 单步执行超时 | 网络慢/训练卡死 | 高级选项调大单步超时；确认是否卡死（先结束任务） |
| G-4.4 | 显存不足 / CUDA out of memory | batch/分辨率过大 | 调小 batch / 输入尺寸 / 换小模型 |
| G-4.5 | 提示"该仓库是模型库，无训练代码" | 仓库只提供预训练权重（hubconf） | 换用论文官方训练仓库，或填训练命令 |

## G-5 数据集失败

| 锚点 | 症状 | 原因 | 动作 |
|---|---|---|---|
| G-5.1 | 未训练（降级安全检查） | 仓库无匹配数据集配置 | 高级选项→数据集：填 YAML 相对路径（如 data/coco128.yaml）或数据包直链（ZIP/TAR，自动下载解压生成配置） |
| G-5.2 | 数据下载失败/源不可达 | 官方源国内不可达（如 MNIST 旧源） | 换镜像直链填入；或填 `__repo_managed__` 让训练代码按其默认源（已切国内可达 S3）下载 |
| G-5.3 | 磁盘不足 | 数据集大 | 云控制台扩容或清理数据盘 |

## G-6 结果与指标

| 症状 | 说明 | 动作 |
|---|---|---|
| 显示"未收集到指标" | 仓库输出格式特殊 | 报告会给出日志证据；可改用标准训练命令重跑 |
| 对比表"论文值—" | 该仓库尚未录入论文基准 | 属正常；可自行对照论文表格 |
| 显示"结果说明：降级…" | 本次没有真正训练 | 按 G-5.1 补数据集后重跑 |

## G-7 重跑与恢复

| 症状 | 动作 |
|---|---|
| 重执行提示"需要密码" | 密码只在本进程内存（安全设计）。在弹出框补输密码即可；重启应用后需重新补 |
| 换机器/换论文 | 填新服务器（G-2）；换论文直接粘新链接；**同一仓库第二次跑会自动预填上次成功配置** |
| 想清空某仓库记忆 | 历史页→仓库档案管理→删除 |

## G-8 手机使用（局域网/远程控制）

| 目标 | 操作 |
|---|---|
| 同一 WiFi 手机访问 | 电脑运行 `start_app_remote.bat`（或已装开机自启）→ 手机浏览器打开控制台打印的 `http://电脑IP:8505` |
| 免口令直达（受信设备） | 首次进入输口令后勾选「信任此设备」→ 浏览器地址栏会带 `?tk=…` → 把该地址存入书签或"添加到主屏"，之后点图标免口令进入 |
| 吊销受信设备 | 侧栏「手机直达与受信设备」→ 逐条吊销或吊销全部（直达链接立即失效） |
| 人在外面控制 | `start_tunnel.bat` 建立到云服务器的 SSH 反向隧道（断线自动重连），云机回环端口经 AutoDL「自定义服务」映射为公网 URL 访问 |
| 打不开（三分法） | ① 电脑上应用是否在跑（控制台窗口在吗）；② 是否同一网络/隧道是否在线；③ 防火墙：以管理员运行 `open_firewall.bat` |
| 开机自启常驻 | 管理员运行 `autostart_install.bat`（卸除用 autostart_uninstall.bat）；电脑勿休眠（电源设置） |

安全须知：远程访问会启用访问口令；受信直达链接等同口令，请勿转发；局域网 http 下同网段可嗅探，建议仅在可信 WiFi 使用。

## 安全与成本须知

- 密码/私钥不落盘、不进日志；仅存进程内存。
- 云端按量计费：任务结束后请及时关闭实例；本应用关窗即断云端会话（远端训练进程会终止）。
- 公开数据集请核对原许可后使用。
